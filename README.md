# Telegram-бот «Расписание Онлайн»

Telegram-бот для поиска расписания занятий по преподавателю, аудитории или группе. Командный проект.

## Стек
- Python, aiogram
- SQLite (`schedule.db`)

## Возможности
- Поиск расписания по преподавателю, аудитории и группе
- Система команд и состояний для навигации в боте
- Кэширование ответов вместо повторных запросов к внешнему API — решение выдержало 100+ пользователей одновременно

## Структура
TG BOT/
├── run.py # точка входа
├── config.py # конфигурация
└── bot/
├── api/ # обращение к внешнему API + кэш
├── db/ # работа с SQLite
├── handlers/ # обработчики команд и сообщений
└── keyboards/ # клавиатуры бота
## Запуск
```bash
cd "Telegram-bot Schedule/TG BOT"
pip install aiogram
python run.py
```
*(если в репозитории есть requirements.txt — используй `pip install -r requirements.txt` вместо этого)*
